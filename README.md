# Это pyDurak
Во-первых, это игра в карточного дурака, написанная на Питоне. Во-вторых, это инфраструктура, в которой можно проводить матчи между компьютерными программами, играющими в дурака (дальше я буду называть их движками, по аналогии с компьютерными шахматами). Сами движки могут быть написаны на любом языке.

Состоит все из нескольких компонентов:
  - **durak-gui** — визуальный интерфейс, в котором можно выбрать движок и сразиться с ним.
  - **durak-autoplay** — консольная утилита, позволяющая стравить между собой два движка. Результат выводится на экран. Сами игры могут писаться в лог.
  - **durak-logviewer** — визуальный просмотрщик логов игр.
  - **durak-dummy** — простенький движок для примера.
  - **durak-nextgen** — NextGen: учет открытых карт и стратегия игры с колодой, точный расчет эндшпиля.
  - **durak-smart-runner** — Smart Runner: метод Монте-Карло по возможным раскладам скрытых карт, тот же точный эндшпиль.
  - **durak-play** — игра против выбранного движка в терминале, без GUI (по умолчанию NextGen).
  - **durak-web** — игра в локальном браузере: новый интерфейс, масштабируемые карты и те же правила и движки.

Подробная документация есть в папке `docs`. Ах да, правила. Обычный подкидной дурак, один на один. Каких-то особых правил типа «первый отбой — пять карт» нет.

## Без GUI

```sh
pip install -e .
durak-play
durak-play --engine dummy
durak-play --engine /path/to/engine
durak-autoplay durak-nextgen durak-dummy --matches-number=1 --match-size=100
pytest --ignore=durak/gui
```

Из исходников терминальная игра запускается и без установки: `python3 -m durak.play`.
В `--engine` можно указать `nextgen`, `smart_runner`, `dummy`, имя исполняемого файла из `PATH` или путь к любому движку с протоколом pyDurak.
Для GUI установите дополнительную зависимость: `pip install -e '.[gui]'`.

## В браузере

```sh
pip install -e .
durak-web
```

Откроется `http://127.0.0.1:8765/`. Нужен только Python 3.10+ и современный браузер: без wxPython, Node.js и подключения к интернету. Из исходников: `python3 -m durak.web`. Другой порт: `durak-web --port 9000`; без автоматического открытия браузера: `durak-web --no-browser`.

Кнопка New deal сразу начинает новую игру с текущим соперником; первым ходит предыдущий победитель. Движок можно сменить в списке Opponent рядом со столом. Свой движок: `durak-web --engine /path/to/engine`. [Подробнее о веб-версии](docs/web.md).
